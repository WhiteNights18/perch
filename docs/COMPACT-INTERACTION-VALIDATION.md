# 紧凑组件与交互改进验证

版本：0.3.0-alpha.1；日期：2026-10-13。

## 实现

- 整体缩放默认 75%，设置范围 50%–125%。100% 的 244×244 小方卡在默认比例下为 183×183；保留每种组件的预设与手动缩放。
- 拖动通过合成器平移连续预览，释放后才提交网格位置；碰撞则回到原位。纯移动不再调整尺寸或重新渲染照片。
- 便签正文点击进入有键盘焦点的编辑窗口；显式简体中文字体、换行、自动保存、Esc/完成退出。卡片只绘制前十二行摘要。
- 时钟同时显示指针和数字时间，每秒检查日期/分钟变化，未显示秒针时不重复绘制同一分钟。
- 默认播放器为本机已安装的 `io.bassi.Amberol.desktop`。封面、底部入口、空闲时的播放按钮可启动播放器；可在设置中改选应用。
- MPRIS 本地封面、封面配色、`xesam:asText` 歌词和歌曲旁同名 UTF-8 LRC。带时间戳的歌词按播放器 Position 同步；读取失败使用明确空状态。图片读取限制普通文件及 64 MB，LRC 限制 200 KB。
- 本地任务支持添加、勾选、删除和持久化，最多 100 条；启动器最多九个已安装应用入口。
- 原照片组件保留；可再增加八个独立相框，分别保存来源、位置、大小和轮播偏好。移除相框不删除图片。照片背景、边框和阴影清除，使用图像自身的圆角透明蒙版。

## 验证范围

- 20 项模型/布局单元测试、GJS 异步保存及真实图片解码通过。
- 真实隔离 GNOME 51：备忘录编辑窗口中文字体与虚拟键盘输入、隐藏/重启恢复、原七种组件功能、全部尺寸预设、原生文件选择器、照片目录更新、主题切换及窗口层级。
- 专项交互：75% 下连续拖动预览和释放清理；任务输入/保存及恢复；多个相框加载及位置恢复；实际打开安装的 Amberol。
- MPRIS 测试播放器明确为合成测试服务，测试图片和歌词也为夹具。通过真实 D-Bus 检查控制指令、专辑图像/背景取色、歌词随播放位置显示，以及本地 LRC 加载。

## 边界

不联网搜索歌词，不下载远程封面；同步取决于播放器是否提供 Position。没有可用歌词时显示提示，不生成歌词。Amberol 已验证启动，尚未用用户个人曲库验证所有音频格式和内嵌歌词；中文输入法候选窗口、混合缩放、多显示器和第三方桌面图标扩展共存仍需日常桌面验收。

平滑拖动已验证为连续位移，尚未测量用户 GPU 上的帧率；这里的隔离会话不能替代日常桌面效果。测试使用独立 XDG 目录和会话总线，不写入用户播放器设置或个人图库。

## 复现

```sh
bash scripts/check.sh
bash scripts/test-shell.sh /tmp/perch-compact-unique
PERCH_FEATURES_ONLY=1 bash scripts/test-shell.sh /tmp/perch-features-unique
```

所有测试目录必须为空。图片解码辅助进程、Wayland 和本地 D-Bus 需可用；实际启动 Amberol 测试要求本机安装 Amberol。

## 发布结果

完整隔离测试和新增功能专项测试均为 PASS。退出编辑后额外检查普通桌面可见性和标题像素，避免截取重挂载过程中的中间帧。隔离测试关闭热角，防止虚拟鼠标初始坐标误触概览；不改变日常桌面的热角设置。
