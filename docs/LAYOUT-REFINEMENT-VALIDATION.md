# 布局与组件设置验证

版本：0.3.0-alpha.3，2026-10-14。

## 改动

- 番茄钟按圆圈可用空间计算整数像素字号。底部为重置、开始、时间菜单，左右图标按钮宽度相同；5/10/15/25/30/50 分钟放入菜单，不再占用圆圈空间。
- 顶栏移除按钮及图标的额外 padding，图标保持 16px，整个按钮目标宽度 24px（100%）。此前只修改按钮 padding，图标主题 padding 仍造成 44px 占位；已通过实际分配宽度检查。
- 启动器使用布局管理器直接分配位置，避免 allocation 回调中更改尺寸导致重复布局和点击错位；1–9 个图标逐排居中，末行对称，自动尺寸使用常规尺寸规格。
- 备忘录弹窗模式预览左上对齐，日期字号增大，弹窗标题简化为“备忘录”。
- 设置保留整体外观页，新增组件页；每个组件的开关、尺寸和选项归为展开子项。组件关闭后子项禁用收起。独立相框不依赖主相框开关。
- 原生排版继续保持 actor 1:1；字体换算为整数像素，并设 11px 下限，提高小字可读性。未改系统字体、抗锯齿、缩放或其他扩展。

## 验证

- `scripts/check.sh`：20 项模型/兼容性测试、GJS 保存与图片检查、严格 schema 和 JavaScript 语法检查通过。
- `work/grouped-prefs-full`：完整 Shell 回归 PASS，含尺寸预设、重启保存、照片轮播、GTK 设置和文件选择器。
- `work/layout-release`：最终布局交互 PASS。检查真实点击打开播放器、任务/备忘录键盘输入、六档时间菜单、文字小于圆圈内径、1–9 个启动图标边界与逐排对称，以及顶栏按钮整个分配宽度不超过 28px。
- `work/prefs-grouped-release`：GTK 组件设置开关同步测试与截图；分别等待设置同步后检查禁用/启用状态。
- 上述 work 目录位于仓库上方的任务目录。截图使用隔离 GNOME 51，会话里的图片、笔记、音乐和重复启动器图标是测试内容。
