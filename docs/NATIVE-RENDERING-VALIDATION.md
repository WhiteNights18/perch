# 原生字体与交互修订验证

版本：0.3.0-alpha.2，2026-10-14。

## 修复与行为

- 原先 Desktop actor 的 0.75 缩放会重采样所有字形。现在 actor 保持 1:1，按目标大小计算整数网格和样式尺寸；生成的样式仅作用于 Perch 桌面，卸载时移除临时文件。系统 HiDPI 仍交给 Shell 处理。
- 音乐取色作用于外层圆角卡片，移除白边。歌词右置、无歌词隐藏，不显示播放状态文案。
- 备忘录弹窗/行内编辑可切换，长文放在滚动容器内，纯文本自动保存；Enter 完成、Ctrl+Enter 换行，预编辑文字交由输入法处理。最后修改日期可隐藏，旧数据没有日期时不伪造日期。
- 任务 Enter 创建、左对齐，完成任务稳定排在后面；启动器名称可隐藏，图标、列数和卡片尺寸适配数量；手动改变尺寸会关闭自动尺寸。
- 番茄钟提供 5/10/15/25/30/50 分钟档位，选档重置当前专注计时；提示音默认关闭。系统状态打开 GNOME 系统监视器。
- 顶栏弹窗中心锚定图标并保留 Shell 边缘避让；月历悬停反馈保留回到今天；编辑外框独立绘制于内容上方；照片左下角移除按钮不删除原图片。

## 边界

隔离会话检查声音调用路径，不等于人工听音验证；尚未覆盖实体输入法候选窗口和所有显示器/分数缩放组合。Markdown 渲染本版不实现。实际桌面安装和已加载代码分别核对，不自动注销用户会话。
