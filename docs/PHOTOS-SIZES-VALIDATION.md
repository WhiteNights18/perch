# 照片与组件尺寸验证

日期：2026-10-13。版本：0.2.0-alpha.2。

## 本轮内容

- 本地单图与目录轮播、自然排序、暂停/上一张/下一张、居中裁切/完整显示、圆角蒙版、文件变化刷新、空目录与坏图提示。
- 八种组件全部有尺寸规格；宽 × 高以 128 逻辑像素为单位，保留原先 32 像素网格的自由缩放。选择新规格只移动目标组件，放不下则保留原尺寸。
- 图片扫描和解码采用可取消异步操作。每个目录最多扫描 5000 条、取 500 张候选图片，不递归；忽略隐藏文件、符号链接和超过 64 MB 的文件。
- 解码边长限制为 1600 像素，居中裁切先裁后缩，避免全景图产生过大中间缓存；渲染只处理当前图片。部分格式的解码器可能有其自身的内存开销。

## 验证

- 17 项 Node 单元测试通过：全部组件规格与最小尺寸一致、扩大时找空位、不改变其他组件、空间不足拒绝、旧数据补充照片字段、文件排序和图像比例，及既有布局/计时/天气测试。
- GJS 真实文件测试通过：PNG 解码、坏图拒绝、取消、文件过滤与自然排序、裁切/完整显示以及圆角透明像素。GdkPixbuf 在本机依赖图像解码辅助进程，需允许本地 IPC。
- 隔离 GNOME 51 会话中验证单图、轮播、手动下一张、暂停后不再切换、空目录和坏图提示。
- 逐一应用全部组件的所有预设，断言实际宽高；保存图片的 2×2、3×3、2×4、4×2 及完整显示截图。重启扩展后照片与尺寸恢复，原便签保持。
- 同时回归已有七种组件的交互和明暗渲染。新增连续明暗切换测试，以及截图中便签、音乐、天气标题区域的像素检查。
- 调整为仅重建受相关配置影响的卡片，布局和主题变化保留实例，避免无关设置重启天气请求、系统采样和媒体服务。
- 缩略预览曾出现部分文字空白；使用原始截图裁片及解码像素复核后确认内容实际完整，未将其记录为 GNOME 渲染故障。
- 空目录内新增图片后自动显示、删除后自动回到空状态；通过真实系统文件选择器选图，确认来源写入并成功渲染。
- 新窗口打开后恢复桌面层级，断言普通模式组件位于可见应用窗口下方。

## 复现

`bash scripts/check.sh`；`bash scripts/test-shell.sh /tmp/perch-photo-unique`。

快速绘制回归：`PERCH_PAINT_ONLY=1 bash scripts/test-shell.sh /tmp/perch-paint-unique`。

图库与截图由测试脚本写入传入的临时目录。测试目录必须为空，需 Python 3、GNOME 51、图像解码器与可用的本地会话环境。
