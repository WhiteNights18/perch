# 组件工作流增强

版本：0.4.0-alpha.1，2026-10-15。

## 行为与数据兼容

- 多笔记在同一个备忘录卡片中通过底部序号菜单切换，+ 创建新笔记。最多 20 条，每条最多 16000 字符，各自保存修改时间和最近 20 个撤销批次。连续输入间隔小于 800ms 时合并，重新打开或切换笔记开启新批次。Ctrl+Z 和撤销按钮均可操作。弹窗与行内编辑共用同一份笔记数据，长文保持可滚动。
- 旧的 `note` 内容与修改时间迁入第一条笔记，并保留兼容字段；未知或损坏数据不覆盖原文件。撤销内容保存在本地状态文件中，不是云同步或加密存储。
- 完成任务默认折叠，展开状态持久化；删除后提供“撤销删除”，最多保留 20 条删除记录，按原顺序恢复，达到 100 条任务上限时不再恢复。
- 音乐换色约 320ms，连续换曲从当前颜色继续。深色背景范围配合白色文字，端点和过渡颜色均满足 4.5:1 对比度。歌词按卡片宽度分配约三分之一空间，无歌词仍隐藏。
- 启动器在普通模式拖动图标到另一图标上排序，释放后保存；离开目标区域则取消。布局编辑模式不进行应用排序。显示名称和仅图标分别保存手动尺寸；自动尺寸开启时仍按数量计算。
- 番茄钟暂停后明确显示继续上一轮。左侧按钮展开新一轮操作，确认后重新开始专注；结束后仍可进入休息阶段。设置用选择项区分仅通知与通知加声音。

## 验证范围

- `scripts/check.sh`：23 项模型测试，包含旧数据、笔记历史、任务删除记录、尺寸记忆、排序与对比度；另有 GJS 保存和真实图片解码检查。
- `work/workflows-1`：首轮新增功能真实键盘鼠标测试 PASS，含 Ctrl+Z、两条笔记切换、滚动、任务展开/撤销、计时继续/新建、真实拖动排序、尺寸切换与重载。
- `work/workflows-final`：PASS，额外验证颜色经过中间值而非直接跳变、删除记录和笔记撤销记录重载后可用。
- `work/workflows-full`：PASS，完整 GNOME Shell 回归，包括原有布局键鼠操作、照片、GTK 设置、MPRIS 与歌词。

work 位于仓库上方的任务目录。测试均在独立 GNOME 51 会话中进行，不读取个人音乐或笔记。声音选项与调用路径经过检查，未进行人工听音确认。日常桌面的当前加载状态单独检查；安装文件不等于当前会话已经换成新代码。
